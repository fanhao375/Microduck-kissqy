# IMU 制作时间线

🎬 **[观看 IMU 手工制作全过程（Bilibili）](https://www.bilibili.com/video/BV1qapz6PERs/)**

制作时间均为 2026 年。先完成独立 IMU 的硬件和真实姿态读取，再接入总线；原 Dynamixel 方案跑通后，复用硬件适配飞特。

**当前状态（2026-10-12 确认）：已在整机上经过长时间使用验证，运行正常，没有发现问题。**

| 时间 | 当时做了什么 |
| --- | --- |
| 08-31～09-02 | 明确需要独立安装在躯干上的 IMU；当时缺少能直接照做的完整官方板级资料，先梳理传感器、处理器和总线的职责。 |
| 09-03～09-04 | 确定最初的总线接口：**ID 200、1 Mbps、Dynamixel Protocol 2.0**，并对齐姿态数据格式。 |
| 09-04 | 选定 **LSM6DSV16X、STM32G031、TLV70433、74LVC2G125**，完成原理图及功能分组摆位。 |
| 09-04～09-07 | 完成约 **22.7 × 25.6 mm 的两层 IMU 板**，完成设计并投板。 |
| 09-07 | 按已经确认的器件和封装采购。 |
| 09-08～09-09 | 贴片、回流并检查焊接，完成首块实板。 |
| 09-09 | 实测 3.3V 电源约 **3.31V**；处理焊接问题、补焊后烧录，先用合成数据验证 MCU 和总线通信。 |
| 09-09 | 首板传感器读取异常后，制作第二块板；把通信能通和传感器真实工作分开确认。 |
| 09-09～09-10 | 接入真实姿态读取及传感器 **SFLP 融合**，从合成数据转入真实传感器输出。 |
| 09-10 | 将 UART 接收改为中断方式；一次 **50 Hz、3393 次、失败 0 次** 的通信验证通过，冻结原版 **A5**。 |
| 09-12 | 规划在保留既有硬件的基础上适配飞特，主要调整通信协议及读取方式。 |
| 09-20 | 实现飞特协议，修复与舵机共线时的通信时序；一次 **3000/3000** 的验证通过。 |
| 09-22～09-23 | 接入 15 个舵机共同运行，连续通信记录达到 **7 万多轮无新增错误**，从单板验证进入整机验证。 |
| 09-23～09-28 | IMU 进入实际站立和行走链路，结合整机继续确认姿态反馈与控制运行。 |
